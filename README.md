# Salda MCB Modbus (AHU) — интеграция для Home Assistant

Кастомная интеграция для Home Assistant, подключающаяся по **Modbus TCP** к контроллеру
вентиляционной установки **Salda MCB / miniMCB**.

Версия **1.0.1** — исправлена ошибка `Unexpected error validating Salda Modbus connection`,
возникавшая на pymodbus ≥ 3.10 из-за переименования аргумента `slave` → `device_id`
во всех вызовах чтения/записи. Теперь `modbus_hub.py` сам определяет версию pymodbus
и использует правильное имя параметра — работает и на старых, и на новых версиях.

| Тип регистра | Кол-во | Платформа HA | Поведение |
|---|---|---|---|
| Holding Register (числовой диапазон) | 489 | `number` | Слайдер/поле для изменения уставок |
| Holding Register (перечисление) | 108 | `select` | Выпадающий список режимов |
| Coil | 80 | `switch` | Переключатель on/off |
| Discrete Input | 157 | `binary_sensor` | Статус/авария (только чтение) |
| Input Register | 104 | `sensor` | Измеряемая величина (только чтение) |

## Установка через HACS

1. HACS → Integrations → меню (три точки) → **Custom repositories**.
2. Добавьте URL этого репозитория, категория **Integration**.
3. Найдите "Salda MCB Modbus (AHU)" в списке интеграций HACS и установите.
4. Перезапустите Home Assistant.
5. **Настройки → Устройства и службы → Добавить интеграцию** → «Salda MCB Modbus (AHU)».
6. Укажите IP-адрес Modbus TCP шлюза, порт (обычно 502), Slave ID (обычно 1) и интервал опроса.

## Если снова видите ошибку подключения

1. Откройте **Настройки → Система → Журналы** и найдите строки от `custom_components.salda_mcb_modbus`
   сразу после `ERROR`/`WARNING` — теперь там печатается точная причина (ConnectionError,
   TypeError от pymodbus, таймаут и т.д.), а не просто "Unexpected error".
2. Проверьте, что IP/порт/Slave ID верны и Modbus TCP шлюз включён и доступен из сети,
   где работает Home Assistant (`ping <IP>`, `nc -zv <IP> 502`).
3. Если в логе видно `pymodbus API mismatch ... keyword 'device_id'` или `'slave'` —
   значит установленная версия pymodbus использует другое имя параметра, чем
   определил автодетект; сообщите версию `pymodbus.__version__` (видна в начале
   лога HA при старте) для донастройки.

## Установка вручную (без HACS)

Скопируйте папку `custom_components/salda_mcb_modbus` в директорию
`config/custom_components/` вашего Home Assistant, затем перезапустите HA и
добавьте интеграцию через UI, как описано выше.

## Важно про адресацию Modbus

В таблице производителя все адреса регистров указаны "с 1" (1-based). По умолчанию
интеграция вычитает 1 при формировании запроса на шину (`ADDRESS_OFFSET = 1` в
`modbus_hub.py`). Если после первого подключения показания сенсоров выглядят
сдвинутыми на 1 регистр, поменяйте `ADDRESS_OFFSET` на `0` в этом файле и
перезапустите HA.

## Обработка ошибок

- Разрыв связи с контроллером → все сущности переходят в `unavailable`, в журнал
  Home Assistant попадает точный диапазон регистров, который не удалось прочитать.
- Если недоступны абсолютно все диапазоны → координатор поднимает `UpdateFailed`,
  видно как ошибка обновления на странице интеграции.
- Аварии/предупреждения самого AHU (перегрев, обрыв ленты ротора, неисправность
  датчика и т.д.) — отдельные `binary_sensor` с `device_class: problem`, попадают
  в диагностическую секцию устройства.
- Ошибки записи (значение вне диапазона, обрыв связи при записи) выбрасывают
  исключение, которое Home Assistant показывает как неудачный вызов службы.
