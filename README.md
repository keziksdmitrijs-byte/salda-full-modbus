# Salda MCB Modbus (AHU) — интеграция для Home Assistant

Кастомная интеграция для Home Assistant, подключающаяся по **Modbus TCP** (или Modbus
RTU-over-TCP через RS-485↔Ethernet шлюз) к контроллеру вентиляционной установки
**Salda MCB / miniMCB**.

## Версия 1.1.0 — форма настройки подключения

Форма настройки теперь выглядит так:

- **Host / IP address** — адрес Modbus TCP шлюза/устройства.
- **TCP port** — обычно 502.
- **Modbus slave (unit) id** — адрес устройства на шине (обычно 1).
- **Modbus framing** — выпадающий список:
  - `Modbus TCP` — стандартный MBAP-заголовок (большинство Ethernet-модулей).
  - `Modbus RTU over TCP (RS-485 gateway)` — для дешёвых RS-485→Ethernet шлюзов,
    которые просто туннелируют "сырые" RTU-кадры (с CRC) через TCP-сокет без
    настоящего MBAP-заголовка. Если ваш шлюз именно такой — обычная Modbus TCP
    связь не подключится вообще, нужен именно этот режим.
- **Address mode (1/0)** — переключатель:
  - `1` — отправлять адрес регистра в точности как в документации Salda (адрес 1
    для первого регистра). Подходит для большинства контроллеров.
  - `0` — строгая 0-based адресация протокола Modbus (вычитать 1 перед отправкой).
  - Если после подключения показания "сдвинуты" (например, видите версию ПО вместо
    температуры), переключите этот параметр и сохраните заново.
- **Polling interval, s** — как часто опрашивать контроллер (по умолчанию 30 с).
- **Add without connection test** — чекбокс. Если включён, интеграция создаётся
  **без** предварительной проверки чтения регистра 1 — то есть даже если пробное
  чтение не проходит (устройство отвечает только на часть регистров, или занято
  ответом на другой мастер шины, или временно недоступно), запись подключения
  всё равно сохраняется, а реальное чтение начнётся в фоновом цикле опроса.

## Диагностика "не подключается"

1. Сначала попробуйте подключиться **без** галочки "Add without connection test" —
   если Home Assistant прямо покажет ошибку `cannot_connect`, значит пробное чтение
   регистра 1 не удалось. Причины по частоте:
   - Неверный **host/port** — проверьте `ping <host>` и `telnet <host> <port>` (или
     `nc -zv <host> 502`) с машины, где работает Home Assistant.
   - Неверный **framing** — если у вас RS-485→Ethernet конвертер без реальной
     поддержки Modbus TCP, переключите на "Modbus RTU over TCP".
   - Неверный **Slave id** — попробуйте 1 (значение по умолчанию у большинства
     Salda AHU), затем проверьте по этикетке/настройкам самого контроллера
     (`HR_SERVICE_Comunication_1_ADDRESS`, адрес 672).
   - Неверный **address offset** — попробуйте переключить между 1 и 0.
2. Если ничего не помогает, включите **"Add without connection test"**, сохраните,
   затем откройте **Настройки → Система → Журналы** и найдите записи от
   `custom_components.salda_mcb_modbus` — там при каждом цикле опроса печатается
   точный диапазон регистров, который не отвечает, и настоящая ошибка pymodbus
   (таймаут, разрыв соединения, неверный CRC при RTU-over-TCP и т.д.).
3. Через **Настройки → Устройства и службы → Salda AHU → Настроить** можно менять
   host/port/slave id/framing/address offset позже без переустановки интеграции.

## Установка через HACS

1. HACS → Integrations → меню (три точки) → **Custom repositories**.
2. Добавьте URL этого репозитория, категория **Integration**.
3. Найдите "Salda MCB Modbus (AHU)" и установите, затем перезапустите Home Assistant.
4. **Настройки → Устройства и службы → Добавить интеграцию** → «Salda MCB Modbus (AHU)».

## Установка вручную (без HACS)

Скопируйте папку `custom_components/salda_mcb_modbus` в `config/custom_components/`,
перезапустите HA и добавьте интеграцию через UI.

## Сущности

| Тип регистра | Кол-во | Платформа HA | Поведение |
|---|---|---|---|
| Holding Register (числовой диапазон) | 489 | `number` | Слайдер/поле для изменения уставок |
| Holding Register (перечисление) | 108 | `select` | Выпадающий список режимов |
| Coil | 80 | `switch` | Переключатель on/off |
| Discrete Input | 157 | `binary_sensor` | Статус/авария (только чтение) |
| Input Register | 104 | `sensor` | Измеряемая величина (только чтение) |
